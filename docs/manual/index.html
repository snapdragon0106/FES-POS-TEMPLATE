スマートフォンがそのままレジになります。
商品をタップして、預かり金を入れて、確定するだけ。

1このシステムでできること

紙とノートでやっていた「レジ・在庫管理・売上集計」を、ぜんぶスマホにまとめたものです。

できること どういうことか
スマホがレジになる 商品をタップするだけで合計金額とおつりが自動で出ます。暗算も電卓も要りません。
何台でも同時に使える レジを2台3台に増やしても、売上と在庫は自動で共有されます。数秒でおたがいの画面に反映されます。
在庫が自動で減る 売れた分だけ残数が減ります。残りが少なくなるとオレンジ色の警告が出て、売り切れた商品はボタンが押せなくなります。
売上がその場で見える 今いくら売れたか、何がよく売れているか、どの時間帯が忙しいかがグラフで分かります。
誰が操作したか残る 会計・取消・在庫補充などの操作は、全部「誰が・いつ・何をしたか」が記録されます。お金のトラブルを防ぐためです。
安心してください 操作を間違えても、あとから取り消せます。また、在庫より多く売ってしまうような操作は、システム側が自動でブロックします。

3ログインのしかた

4つのステップです。2回目からは合言葉とPINだけなので、10秒で終わります。

1合言葉を入力する

クラス共通の合言葉を入れて 入場する を押します。関係のない人が開けないようにするための入口です。

合言葉は担当者から直接聞いてください（この説明書には書きません）。

他のクラスの人に教えないこと 合言葉が漏れると、売上データを見られたり書き換えられたりする可能性があります。

2自分の個人番号を入れる

出席番号ではなく、4桁の個人番号です（例：2年3組1番なら 2301。分からなければ管理者に聞いてください）。自分の番号を入れて 次へ を押します。

番号を入れると、次の画面に自分の名前が出ます。名前が違っていたら番号の入力ミスなので、番号を変更 で戻ってください。

3【初回だけ】PINを決める

はじめてログインするときだけ、この画面が出ます。好きな4桁の数字を決めて、確認用にもう一度同じ数字を入れます。

これが次回からのあなた専用の暗証番号になります。忘れないものにしてください。

設定したPINは、管理者が承認すると使えるようになります（「管理者の承認待ちです」と出ます）。管理者に声をかけ、承認されたらもう一度同じPINで入室してください。

4【2回目から】PINを入力する

名前が合っていることを確認して、自分で決めた4桁のPINを入れ、入室する を押します。

これでレジ画面が開きます。

PINは絶対に人に教えないでください 会計・取消などの操作はすべて「誰がやったか」が記録に残ります。PINを他人に教えると、その人の操作があなたの名前で記録されてしまいます。
PINを忘れてしまった場合は、管理者に言えばリセットしてもらえます。自分では戻せません。

4レジの使い方

ここがいちばん大事です。当日レジに立つ人は、ここだけ覚えれば大丈夫。

まず画面の見方

上半分が商品ボタン、下半分がカートです。

それぞれの商品ボタンには、右上に 残○ と現在の在庫数が出ています。

  • オレンジ色で「残りわずか」＝在庫が少ない。補充の合図
  • 灰色で「売切」＝在庫ゼロ。ボタンが押せなくなります

1商品をタップする

売れた商品のボタンをタップします。タップするたびに1個ずつカートに入ります。たこ焼き2個なら2回タップ。

画面を下にスクロールするとカートが見えます。ここで間違いに気づいたら:

  • − ＋ で数を増減できます
  • 右端のゴミ箱でその商品を取り消せます

合計金額が合っていることを確認して、緑色の 会計へ進む を押します。

2お客様から受け取った金額を入れる

「お会計」の画面が出ます。上に商品の一覧と合計金額が表示されます。

お客様から預かった金額を「預かり金額」に入力します。よく使う金額はボタンで入れられます。

  • ちょうど … 合計と同じ額（おつりなし）
  • ¥1,000 ¥5,000 ¥10,000 … その金額を一発入力

3おつりを確認して渡す

金額を入れると、下にお釣りが大きく緑色で出ます。この金額をお客様にお返しします。

預かった金額が足りないときは、赤い字で 不足 ¥○○ と出て、確定ボタンが押せません。もう一度金額を確認してください。

4確定する

おつりを渡したら 会計を確定する を押します。「会計完了！ ○番」と出て、カートが空になります。

その番号（注文番号）をお客様に伝えます。商品は、受け渡しの係が番号を呼んで渡します（6章）。番号はカートの上の「前回 ○番」でも確かめられます。

この瞬間に、売上と在庫がすべての端末に反映されます。次のお客様をどうぞ。

確定は最後に 確定を押す前にお金のやりとりを済ませてください。確定後の取り消しは管理者しかできません。
連打しても大丈夫です 確定ボタンを何度も押してしまっても、二重に会計されることはありません。同じように、2台のレジが同時に最後の1個を売ってしまうこともシステムが防いでいます。

6それぞれの画面の説明

担当になったときに読めば十分です。

受け渡し — 会計した注文を渡す

会計と商品を渡す場所が別のとき、受け渡しの係はこの画面を開いておきます。どのレジで会計しても、数秒で注文が出ます（番号と商品と個数。新しい注文は枠が光り、スマホが振動します）。

  1. お客様に番号を聞く（または番号を呼ぶ）
  2. その番号の商品を渡す
  3. 渡した を押す → 一覧から消える

間違えて押したときは、下の「さっき渡した注文」から 戻す で戻せます（15分以内）。音なし を押すと、新しい注文のときに音が鳴るようになります。この画面を開いている間は、スマホの画面が消えにくくなります。

売上 — 今どれだけ売れているか

在庫 — 残りがどれだけあるか

履歴 — 会計の一覧と、間違えたときの取消

間違えて会計してしまったら

自分で直そうとせず、すぐ管理者に声をかけてください。取り消された会計は、下のように表示されます。

7困ったときは

当日よくある場面をまとめました。システムが止まったときの詳しい対応は、別紙の「障害対応手順書」にあります。

画面の上に赤い帯が出た
サーバーとつながっていない合図です。表示されている在庫や売上は古い可能性があります。 「この端末がインターネットにつながっていません」ならあなたのスマホの電波の問題なので、Wi-Fiやモバイルデータを確認してください。 「サーバーに接続できません」なら管理者に伝えて、帯の 再接続 を押してみてください。 会計できない状態が3分続いたら、紙に記録して営業を続けます（障害対応手順書の1章）。
会計を押したら「通信が途切れました」と出た
会計が記録されたかどうか分からない状態です。カートはそのままで、もう一度「会計を確定する」を押してください。 1回目がじつは記録されていても、二重には記録されません（そのときは「先ほどの送信で記録済みでした」と出ます）。 ただし、別のスマホやページの読み込み直しのあとで打ち直すと二重になるので、それはしないでください。
「在庫が不足しています」と出て会計できない
本当に在庫が無くなっています。他のレジが先に売った可能性もあります。現物を確認して、まだあるなら管理者に在庫の補充をお願いしてください。
間違えて会計を確定してしまった
あわてずに管理者を呼んでください。取り消してもらえば、売上も在庫も自動的に元に戻ります。
他のレジで売れたはずなのに、在庫の数が減っていない
画面の更新待ちです。最大8秒で自動的に新しくなります。急ぐときは 今すぐ同期 を押してください。
PINを忘れてログインできない
管理者に伝えてください。次のログインで新しいPINを決め直せるようにしてもらえます。
「試行回数が多すぎます」と出た
PINを5回続けて間違えたため、5分間ロックされています。5分待てば自動的に解除されます。それまでは正しいPINを入れても通りません。
画面が真っ白／読み込みが終わらない
電波を確認して、ページを再読み込み（引っぱって更新）してください。それでもダメなら、いったんブラウザを閉じて開き直します。会計済みのデータが消えることはありませんので安心してください。
急に画面が暗くなった／明るくなった
ダークモードの切り替えです。スマホでは右上の月・太陽のマーク、パソコンでは左下のボタンで戻せます。表示が変わるだけで、データには影響しません。
スマホの充電が切れそう
別の端末でログインすれば、そのまま続けられます。データはすべてサーバー側にあるので、端末を替えても何も失われません。モバイルバッテリーを用意しておくと安心です。
レジを他の人に交代する
必ず 退室する でログアウトしてから交代してください。そのまま渡すと、あなたの名前で記録が残り続けてしまいます。

8当日のお願い

お金を扱うので、この6つだけは守ってください。

  1. 必ず自分の個人番号でログインする 人の番号を借りないでください。記録がその人のものになってしまい、あとで金額が合わないときに原因が追えなくなります。
  2. PINは誰にも教えない 友達にもです。教えてしまったら、管理者に言って設定し直してください。
  3. 確定を押す前に、お金のやりとりを終える 「先に確定 → お客様が財布を忘れた」が一番面倒です。おつりを渡してから確定しましょう。
  4. 間違えたら、すぐ管理者を呼ぶ 自分で直そうとせず声をかけてください。早いほど簡単に直せます。隠すのがいちばん困ります。
  5. レジを離れるときは退室する 置きっぱなしにすると、誰でもあなたの名前で操作できてしまいます。
  6. システムが止まっても、お店は止めない 3分直らなければ、紙の記録用紙に書いて営業を続けます。お金はいつも通り受け取り、おつりもいつも通り渡します。紙の分はあとで管理者が入力するので、売上も在庫も元通りになります。

9裏側のしくみ

興味がある人向けです。読まなくても使えます。

お金がずれないようにしている工夫

工夫なぜそうしているか
金額はスマホ側で計算しない 合計金額はサーバー側で商品の値段から計算し直しています。スマホから送られてきた金額をそのまま信じると、細工された金額で会計できてしまうからです。
在庫のチェックは「順番待ち」で行う 2台のレジが同時に最後の1個を売ろうとしたとき、片方が終わるまでもう片方を待たせています。これがないと在庫がマイナスになります。
PINは元に戻せない形で保存 PINは暗号化して保存しているため、データベースを見ても数字は分かりません。管理者でも他人のPINは見られません。
権限をサーバー側でも確認 管理者用のボタンを隠すだけでなく、サーバー側でも「本当に管理者か」を毎回確かめています。画面をいじっても突破できません。
操作ログは消せない 会計・取消などの記録は残り続けます。あとから「誰が何をしたか」を確認できるようにするためです。

使っている技術

画面は React、サーバーは Node.js（tRPC）、データの保存は TiDB というクラウド上のデータベースです。 サーバーは Render というサービスで24時間動いています。 デザインは HarmonyOS の動きの設計を参考にしていて、ボタンを押したときの反応やカードの動きはすべて実機の値をもとに調整しています。

このシステムについて 文化祭のクラスの物販のために作られたシステムです。 使ってみて「ここが使いにくい」「こうだったらいいのに」と思ったところがあれば、管理者に伝えてください。
